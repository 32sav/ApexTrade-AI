# ApexTrade AI

### Multi-Market Algorithmic Trading System

ApexTrade AI is a modular algorithmic trading system designed to analyse financial markets, generate trading signals, manage risk, and automate trade execution across Deriv and MetaTrader 5.

## Project Vision

To develop an intelligent, scalable and reliable trading automation platform that combines multiple trading strategies through a confluence engine.

## Supported Markets

- Deriv synthetic indices
- Forex: XAUUSD, EURUSD and GBPUSD
- Additional supported instruments in future releases

## Core Features

- Real-time market data analysis
- Multiple technical trading strategies
- Strategy confluence scoring
- Automated trade execution
- Independent risk management
- Manual trading override
- Trade history and performance monitoring
- PostgreSQL database integration
- Interactive trading dashboard
- Telegram notifications

## Technology Stack

| Component         | Technology              |
| ----------------- | ----------------------- |
| Backend           | Python, FastAPI         |
| Frontend          | React                   |
| Database          | PostgreSQL              |
| Deriv Integration | Deriv WebSocket API     |
| Forex Integration | MetaTrader 5 Python API |
| Data Analysis     | Pandas, NumPy           |
| Version Control   | Git and GitHub          |

## System Architecture

ApexTrade AI consists of:

1. Market Data Engine
2. Strategy Engine
3. Confluence Engine
4. Risk Management Engine
5. Execution Manager
6. Monitoring Dashboard

## Development Status

Currently in the technical research and system design phase.

All trading development and validation will initially use demo accounts and simulated execution.
